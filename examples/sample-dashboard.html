What this run did not establish

  • History and provenance were not measured: disabled in 0.1.2. The tool starts no git program in this release; history returns in a later release with a contained design.
  • No corpus given, so duplication against known public projects was not measured (--corpus DIR).
  • Screen mode is mechanical. No score here is a judgement, and every dimension is marked unverified until a deep pass.
  • Regex sweeps find shapes, not meanings: a fixture can look like a credential and a quoted licence can look like a breach. Every flag names its evidence, a file and line or a command or commit, so a reader can check.

What this page does not show

  • Whether the code works. Nothing here runs a project's own tests or uses its output.
  • Paraphrased copying. Duplication is measured by content hash against a corpus you supply, so it finds identical files and misses rewritten ones.
  • Anything outside the corpus you pointed the tool at.
  • Whether a person or a model wrote the code. There is no reliable detector, and a false accusation costs more than a missed one.
  • Judgement. A screen-mode dimension shows a dash because the screen measures signals and does not score.
