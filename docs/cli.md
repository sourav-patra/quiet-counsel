# Command reference

Generated by `tools/gen_cli_docs.py` from the parser. Edit the parser, not this file.

`quiet-counsel` Score an agent project on what its repository contains, with evidence for every number. Measures and flags; a person decides.

| argument | meaning |
|---|---|
| `--version` | show program's version number and exit |

## quiet-counsel classify

What kind of project this is, and on what evidence.

| argument | meaning |
|---|---|
| `path` | the project directory |
| `--json` | print the result as JSON |

## quiet-counsel screen

A mechanical pass over one or many projects.

| argument | meaning |
|---|---|
| `paths …` | one or more project directories |
| `--corpus` | a directory of known projects, for duplication checks |
| `--out` | write one scorecard per project into this directory |
| `--event-start` | the date the event opened, to flag earlier history |
| `--event-end` | the date the event closed |
| `--honour-ignore` | apply the project's .scanignore to one project: findings in the paths it lists become information, so a project can lower its own band under this option |
| `--no-ignore` | accepted and does nothing: a .scanignore is not applied unless --honour-ignore is passed |

## quiet-counsel integrity

Provenance, duplication, licence and claim checks.

| argument | meaning |
|---|---|
| `path` | the project directory |
| `--corpus` | a directory of known projects, for duplication checks |
| `--min-bytes` | ignore files smaller than this when comparing (default 400) |

## quiet-counsel dashboard

Render scorecards as one html page.

| argument | meaning |
|---|---|
| `cards …` | scorecard JSON files |
| `--out` | where to write the page |
| `--title` | the page title |
| `--strict` | refuse to build if any scored dimension carries no evidence |

## quiet-counsel check

Check scorecards against the contract the dashboard needs.

| argument | meaning |
|---|---|
| `cards …` | scorecard JSON files |

## quiet-counsel verdict

Write a release verdict from one scorecard.

| argument | meaning |
|---|---|
| `scorecard` | the scorecard JSON file |
| `--gate-status` | result of the project's own release gate (default: missing) |
| `--out` | where to write the verdict JSON |
