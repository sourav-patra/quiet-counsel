# Bands

| band | meaning | what follows |
|---|---|---|
| blocked | a critical flag: a credential shape outside test paths, a copyleft component under a permissive licence, or text addressed to the evaluator | a person rules before anything else happens |
| review | a serious flag, or a claim the repository contradicts | goes to triage, then a deep review, however good it looks |
| shortlist | clean screen with tests, a declared licence and a CI definition | goes to a deep review |
| screened | clean screen, thin signals | a deep review if the cohort is small or a judge asks |

A band is computed from flags alone, so two projects in the same band can be nothing alike. The
dashboard shows each project's full profile for exactly that reason.

## What a screen cannot claim

Every dimension in a screened card is `unverified` and carries no score. The screen measures
around thirty signals, each with the command that produced it, and stops there.

It cannot tell whether the code works, whether paraphrased code was copied, whether a claim in
prose is true, or whether a person or a model wrote the work. The dashboard lists those limits
on every page.
